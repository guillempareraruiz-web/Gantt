# Asignar operarios

> Asigne uno o varios operarios a una operación (o a varias a la vez) y ajuste las horas de cada uno.

## ¿Qué hace?

Esta pantalla muestra, para la operación seleccionada:

- **Operarios asignados**: los que ya están trabajando en la operación, con las horas previstas y sus capacitaciones.
- **Operarios disponibles**: los que pueden asignarse todavía.

Arriba se indica cuántos operarios necesita la operación; abajo, el resumen le avisa con color si faltan operarios (rojo), si está justo (verde) o si hay más de los necesarios (naranja).

## Cómo se usa

1. En la lista de **Operarios disponibles** (derecha), elija el operario que quiera añadir y haga **doble clic** sobre él. Pasará a la lista de asignados.
2. En la lista de **Operarios asignados** (izquierda), puede ajustar las **horas** de cada operario escribiendo directamente en la columna.
3. Para quitar un operario, selecciónelo en la lista de asignados y pulse **Desasignar seleccionado** (o haga doble clic sobre él).
4. La casilla **Solo capacitados** filtra la lista de disponibles para mostrar únicamente a quienes saben hacer la operación. Desmárquela si quiere ver a todos.
5. Cuando termine, pulse **Aceptar** para guardar, o **Cancelar** para descartar los cambios.

## Cuando asigna a varias operaciones a la vez

Si abrió la pantalla con varias operaciones seleccionadas, cada operario que añada o quite se aplica **a todas ellas** de golpe. El resumen y las necesidades mostradas son los totales del conjunto.

## Consejo

Use el color del resumen como guía rápida: mientras esté en rojo, a la operación todavía le faltan operarios para quedar cubierta.
